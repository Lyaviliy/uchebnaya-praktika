# Разработка интерфейса (UI) по руководству по стилю

HTML/CSS/JS, оформление по `Screenshot_2.png`.

- Заголовок страницы: **«CRM: Список партнеров и скидок»**
- Иконка во вкладке браузера: `public/resources/icon.svg`
- Логотип компании в шапке: `public/resources/logo.svg`
- Главный макет: список карточек партнёров. В карточке: «Тип | Наименование» крупно, процент скидки справа, ниже директор, телефон, рейтинг
- Шрифт Segoe UI, белый фон, карточки в тонкой серой рамке; ненулевая скидка выделена цветом

| Файл | Назначение |
|---|---|
| `public/index.html` | разметка: шапка с логотипом, заголовок, список |
| `public/styles.css` | шрифты, цвета, рамки, отступы |
| `public/app.js` | загрузка партнёров и отрисовка карточек |

Внешний вид результата — `screenshot_result.png`. Страница получает данные с сервера, запуск — в папке `итоговое_приложение`.
