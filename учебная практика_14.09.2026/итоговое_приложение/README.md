# Наполнение интерфейса, отладка и стресс-тестирование

Итоговое приложение «CRM: Список партнеров и скидок»: Node.js-сервер + страница в браузере + PostgreSQL.
Список партнёров берётся из БД, скидка рассчитывается автоматически.

```
src/
  server.js          HTTP-сервер: страница + API /api/partners, /api/partners/:id
  partnerService.js  SQL с SUM(quantity) + расчёт скидки
  discount.js        функция скидки
  db.js, config.js   подключение к PostgreSQL
public/              интерфейс (HTML/CSS/JS, логотип и иконка в resources/)
db/                  schema.sql, seed.sql
scripts/             initDb.js, demoDiscounts.js, stressTest.js
test/                unit-тесты
```

## Запуск
Нужны Node.js 20+ и PostgreSQL (пользователь `postgres`, пароль `postgres`; иначе поправить `src/config.js`).
```bash
npm install        # поставить драйвер pg
npm run db:init    # создать базу praktika, таблицы и данные
npm start          # открыть http://localhost:3000
```
Проверки:
```bash
npm test           # unit-тесты и покрытие
npm run stress     # стресс-тест (сервер должен быть запущен в соседнем терминале)
```

## Отладка: обработанные ситуации
| Ситуация | Поведение |
|---|---|
| У партнёра нет продаж: `SUM(quantity) IS NULL` | объём 0, скидка **0%** (`toQuantity` в `partnerService.js`) |
| `SUM` из pg приходит строкой (тип bigint) | приводится к числу перед расчётом |
| Нет директора, телефона, рейтинга | «Директор не указан», «Телефон не указан», «Рейтинг: нет» |
| База данных недоступна | API отвечает 500 с понятным текстом, сервер не падает, на странице сообщение об ошибке |
| Неизвестный партнёр / адрес | 404 |
| Попытка выйти за папку `public` (`../`) | доступ закрыт |
| Данные из БД с HTML внутри | выводятся через `textContent`, не исполняются |

Тестовые партнёры в `db/seed.sql` подобраны так, чтобы показать все уровни скидки: 0%, 5%, 10%, 15% и партнёра без продаж.
