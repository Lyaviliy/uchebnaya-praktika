# Подготовка данных и импорт (ETL)

Исходные файлы: `raw/import_partners.csv`, `raw/import_sales.txt`.
СУБД: PostgreSQL. Структура таблиц — `schema.sql` из задания «Написание DDL-скрипта».

## Файлы
| Файл | Назначение |
|---|---|
| `raw/` | исходные файлы без изменений |
| `clean.py` | очистка данных (Python, только стандартная библиотека) |
| `clean/` | очищенные CSV, готовые к импорту |
| `clean_report.txt` | отчёт об аномалиях, который печатает `clean.py` |
| `import.sql` | импорт через `\copy` + проверочные `SELECT COUNT(*)` |
| `import_result.txt` | вывод `psql` при выполнении `import.sql` |

## Найденные аномалии и что с ними сделано

**import_partners.csv**
| Строка | Аномалия | Решение |
|---|---|---|
| все | переносы строк Windows (CRLF) | читаются корректно модулем `csv` |
| id=1, id=3 | лишние пробелы в начале и конце названия | обрезаны |
| все | тип организации (ООО, ИП, ТК) слит с названием | вынесен в справочник `partner_types` (3НФ) |
| id=1 | телефон в формате `+7 (999) 111-22-33` | приведён к единому виду `+79991112233` |
| id=2 | пустой телефон | записан `NULL` |
| id=3 | пустой рейтинг | записан `NULL` |
| id=1, id=2 | рейтинг дробный (4.8), а не целый | тип поля `rating` — `DECIMAL(3,1)` |

**import_sales.txt**
| Строка | Аномалия | Решение |
|---|---|---|
| все | разделитель — табуляция, переносы CRLF | учтено при чтении |
| sale_id=102 | дата `15.03.2026` вместо `YYYY-MM-DD` | приведена к `2026-03-15` |
| sale_id=104 | ссылка на несуществующего партнёра `partner_id=4` | строка исключена (нарушила бы внешний ключ) |
| все | товар указан названием, а не id | товары вынесены в таблицу `products`, в продажах — `product_id` |

Дополнительно проверяются дубликаты (по `partner_id`, ИНН, email, `sale_id`), формат ИНН (10 или 12 цифр), положительность количества и суммы. В этих файлах таких нарушений не найдено.

Поскольку в исходных данных нет справочной информации о товарах, она сформирована при очистке: тип всех товаров — «Бытовая химия», артикул — `ART-0001` и т.д., `min_price` — цена за единицу (`total_amount / quantity`).

## Как запустить
```bash
python clean.py
psql -U postgres -d praktika -f ../ddl_скрипт/schema.sql
psql -U postgres -d praktika -f import.sql
```
Альтернатива `\copy` — мастер импорта DBeaver: ПКМ по таблице → «Импорт данных» → CSV из папки `clean/`, в том же порядке, что в `import.sql`.
