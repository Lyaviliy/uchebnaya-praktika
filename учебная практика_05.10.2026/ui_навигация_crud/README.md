# Разработка UI, навигации и CRUD-форм

Итоговое приложение «CRM» (Node.js + HTML/CSS/JS + PostgreSQL). Остальные задания дня ссылаются на эту папку для запуска.

## Окна
| Окно | Файлы | Заголовок |
|---|---|---|
| **MainWindow** — список партнёров из БД, поиск, скидка | `public/index.html`, `main.js` | `CRM: Реестр партнеров` |
| **PartnerEditWindow** — добавление и редактирование | `public/partner.html`, `partner.js` | `CRM: Карточка партнера [Добавление]` / `[Редактирование]` |
| **PartnerHistoryWindow** — продажи партнёра (товар, количество, дата) | `public/history.html`, `history.js` | `CRM: История реализации продукции — [Название]` |
| Калькулятор материалов | `public/calculator.html`, `calculator.js` | `CRM: Калькулятор материалов` |

Везде: логотип в шапке, иконка во вкладке, единый `styles.css` по руководству по стилю.

## Форма партнёра
Наименование, Тип (выпадающий список из справочника), ИНН, Рейтинг (только целое ≥ 0), Адрес, Директор, Телефон (маска `+7 (999) 123-45-67`), Email. У всех полей подсказки-плейсхолдеры, у телефона, email, ИНН и рейтинга ещё всплывающие подсказки. ИНН в форме обязателен, потому что он обязательный и уникальный в БД.

## Навигация
- Главная: щелчок выбирает партнёра → «Изменить» или «История продаж»; двойной щелчок сразу открывает карточку; «Добавить партнера»; «Калькулятор материалов»
- id партнёра передаётся через адрес (`partner.html?id=5`, `history.html?partner_id=5`)
- Во всех окнах кнопка **«Назад»**; если в карточке есть несохранённые изменения, сначала предупреждение

## Синхронизация
Сохранение → `INSERT` / `UPDATE` в БД → диалог «Сохранено» → возврат на главную, список перерисовывается заново из БД (в том числе при возврате кнопкой браузера).

## Запуск
Нужны Node.js 20+ и PostgreSQL (`postgres` / `postgres`, иначе поправить `src/config.js`).
```bash
npm install
npm run db:init    # база, схема, загрузка data/*.csv и ETL
npm start          # http://localhost:3000
npm test           # 27 unit-тестов
npm run stress     # стресс-тест (сервер должен быть запущен)
```
