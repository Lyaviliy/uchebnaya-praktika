# Разработка интерфейса истории реализации продукции

Новое окно **PartnerHistoryWindow**: `public/history.html` + `public/history.js`.

- **Заголовок окна:** `CRM: История реализации продукции — [Название партнера]`, название подставляется после загрузки данных
- **Стиль** тот же, что у всего приложения: шрифт Segoe UI, логотип в шапке, иконка во вкладке, серые рамки, общий `styles.css`
- **Переход:** на главной щелчком выбираешь партнёра (карточка подсвечивается), кнопка «История продаж» становится активной и открывает `history.html?partner_id=5`. До выбора кнопка неактивна
- **Таблица:** Наименование продукции, Количество (шт.), Дата продажи (ДД.ММ.ГГГГ), внизу итог по количеству

## SQL-запрос (`src/partnerService.js`, `SALES_SQL`)
```sql
SELECT pr.name AS product_name, sh.quantity, to_char(sh.sale_date, 'DD.MM.YYYY') AS sale_date
FROM sales_history sh
JOIN products pr ON pr.id = sh.product_id
WHERE sh.partner_id = $1
ORDER BY sh.sale_date DESC
```
`JOIN` подтягивает название товара вместо его id, `to_char` переводит дату в привычный формат.

Обработаны случаи: у партнёра нет продаж (сообщение вместо пустой таблицы), партнёр не найден или не передан (диалог ошибки).
Запуск приложения — в папке `интеграция_и_тестирование`.
