# Разработка ядра алгоритма расчёта материалов

Метод `calculateMaterialAmount(productTypeId, materialTypeId, quantity, param1, param2, directory)` в `src/materialCalculator.js`.

## Логика
1. Базовый расход на 1 ед. = `param1 × param2 × коэффициент типа продукции`
2. Общий чистый расход = базовый расход × `quantity`
3. Итог с учётом брака = чистый расход × `(1 + процент брака / 100)`
4. Округление до целого вверх (`Math.ceil`)

Перед округлением результат очищается от погрешности дробных чисел (`0.1 × 3` в JavaScript = `0.30000000000000004`), иначе `3.0000000000000004` округлился бы до 4 вместо 3.

## Обработка ошибок — возврат `-1`, без исключений
- id типа продукции или материала не целое положительное число, или такого типа нет в справочнике
- `param1` / `param2` не положительные (≤ 0, NaN, бесконечность)
- `quantity` ≤ 0 или дробное

## Справочники
Метод получает справочники параметром `directory`:
- в приложении — `dbDirectory` из `src/materialService.js`: запросы к таблицам БД `product_types.coefficient` и `material_types.defect_percent`
- в тестах — мок-объект с теми же двумя методами

Таблица `material_types` и колонка `coefficient` добавлены в `db/schema.sql`, значения в `db/seed.sql`:

| Тип продукции | Коэффициент | | Тип материала | Брак |
|---|---|---|---|---|
| Бытовая химия | 1.2 | | Порошковое сырьё | 0.5% |
| Моющие средства | 1.8 | | Жидкое сырьё | 1.2% |
| Средства для ухода | 2.35 | | Упаковка | 0.25% |
