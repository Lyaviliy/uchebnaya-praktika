# Интеграция метода расчёта и комплексное тестирование

Полное приложение «CRM» (Node.js + HTML + PostgreSQL). Остальные задания дня ссылаются на эту папку для запуска.

## Калькулятор материалов
Окно `CRM: Калькулятор материалов` (`public/calculator.html`, `public/calculator.js`), открывается кнопкой «Калькулятор материалов» на главной.
- типы продукции и материалов — выпадающие списки из БД (видно коэффициент и процент брака)
- количество и два параметра, дробь можно вводить через точку или запятую
- «Рассчитать» → `POST /api/materials/calculate` → метод `calculateMaterialAmount` → результат на форме

## Отладка
| Ввод | Поведение |
|---|---|
| отрицательный или нулевой параметр | метод возвращает `-1`, форма показывает диалог «Ошибка расчёта» с пошаговой подсказкой |
| количество 0 или дробное | то же |
| не выбран тип / несуществующий id (в т.ч. запрос в обход формы) | то же |
| сервер или БД недоступны | диалог ошибки, страница продолжает работать |

Интерфейс не падает ни в одном случае; все случаи `-1` записываются в журнал `logs/app.log`.

## Проверка кода по ТЗ
- одна команда на строку
- именование camelCase для функций и переменных, UPPER_CASE для констант, snake_case только в SQL
- комментарии только в неочевидных местах: очистка погрешности перед округлением, смысл `-1`, передача id через адрес, экранирование имени БД

## Запуск
```bash
npm install
npm run db:init
npm start          # http://localhost:3000
npm test           # все unit-тесты
```
