# Интеграция формы с БД (CRUD-операции и обновление UI)

Полное приложение «CRM: Реестр партнеров» (Node.js + HTML + PostgreSQL). Остальные задания дня ссылаются на эту папку для запуска.

## Режимы карточки партнёра
| Режим | Как открыть | Что происходит при «Сохранить» |
|---|---|---|
| Добавление | кнопка «Добавить партнера» на главной | `POST /api/partners` → `INSERT`, окно закрывается, список на главной загружается заново |
| Редактирование | клик (или Enter) по карточке партнёра | форма сама заполняется из `GET /api/partners/:id`; `PUT /api/partners/:id` → `UPDATE` |

## API (`src/server.js`)
| Метод | Адрес | Назначение |
|---|---|---|
| GET | `/api/partners` | список партнёров со скидками |
| GET | `/api/partners/:id` | один партнёр для заполнения формы |
| POST | `/api/partners` | создать партнёра |
| PUT | `/api/partners/:id` | изменить партнёра |
| GET | `/api/partner-types` | справочник для выпадающего списка |

## Ссылочная целостность на уровне кода (`src/partnerService.js`)
- Перед `INSERT`/`UPDATE` проверяется, что выбранный тип партнёра есть в `partner_types` (`ensurePartnerTypeExists`), даже если запрос пришёл в обход формы.
- `UPDATE` несуществующего партнёра → 404 с понятным текстом.
- Повтор ИНН или email → 409 «Партнёр с таким ИНН уже существует».
- Те же правила валидации, что в форме, повторно проверяются на сервере (`public/validation.js` общий для обоих).

## Запуск
Нужны Node.js 20+ и PostgreSQL (`postgres` / `postgres`, иначе поправить `src/config.js`).
```bash
npm install
npm run db:init
npm start          # http://localhost:3000
npm test           # unit-тесты: скидка + валидация
```
