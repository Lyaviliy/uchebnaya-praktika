# Разработка формы добавления/редактирования партнёра

Форма **PartnerEditWindow**: `public/partner.html` (разметка), `public/partner.js` (логика), `public/styles.css` (оформление).

| Поле | Элемент | Подсказка |
|---|---|---|
| Наименование * | текстовое поле | «Например: Чистый Дом» |
| Тип партнера * | выпадающий список (ЗАО, ООО, ИП, ПАО, ТК — из справочника БД) | «Выберите тип…» |
| ИНН * | текстовое поле, только цифры | «10 или 12 цифр» |
| Рейтинг | текстовое поле, целое неотрицательное | «Целое число от 0 до 10» |
| Адрес | текстовое поле | «г. Москва, ул. Лесная, д. 5» |
| ФИО директора | текстовое поле | «Иванов Иван Иванович» |
| Телефон | поле с маской: при вводе `89991234567` превращается в `+7 (999) 123-45-67` | «+7 (999) 123-45-67» + всплывающая подсказка |
| Email компании * | поле email | «name@company.ru» + всплывающая подсказка |

ИНН добавлен к полям из ТЗ, потому что в спроектированной БД он обязательный и уникальный.

Подсказки — `placeholder` (серый текст в пустом поле) и `title` (всплывающая подсказка при наведении).
Комментарии в коде оставлены только там, где логика неочевидна: передача id партнёра через адрес, пустая первая опция списка, маска телефона, проверка целого рейтинга.

Запуск приложения — в папке `crud_интеграция`.
