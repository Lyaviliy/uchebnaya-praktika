# Проектирование многооконной архитектуры и навигации

Приложение разделено на два окна (страницы):

| Окно | Файлы | Заголовок окна |
|---|---|---|
| **MainWindow** — список партнёров | `public/index.html`, `public/main.js` | `CRM: Реестр партнеров` |
| **PartnerEditWindow** — добавление/редактирование | `public/partner.html`, `public/partner.js` | `CRM: Карточка партнера [Добавление]` или `[Редактирование]` |

## Переходы
- MainWindow → кнопка **«Добавить партнера»** → PartnerEditWindow в режиме добавления
- MainWindow → клик по карточке партнёра → PartnerEditWindow в режиме редактирования (`partner.html?id=5`, id передаётся через адрес)
- PartnerEditWindow → кнопка **«Назад»** → возврат на MainWindow. Если в форме есть несохранённые изменения, сначала спрашивается подтверждение, чтобы не потерять данные
- При возврате список на главной загружается заново (в том числе при кнопке «назад» браузера, событие `pageshow`), поэтому всегда показывает актуальные данные

Ошибки загрузки не обрывают работу: показывается диалог с описанием, приложение продолжает работать.

Скриншоты — `screenshots/`. Запуск приложения — в папке `crud_интеграция`.
